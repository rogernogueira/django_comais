Armadilhas · 8.1

Alucinação numérica

A IA "completa" um número que não existe no documento. Plausível e falso.

Sintoma

Número fantasma

Aparece um valor que ninguém acha no documento original. O número "parece certo" mas não bate em nenhuma página.

Causa

Falta de citação

O prompt não exigiu campo de fonte. A IA "completou" com plausibilidade quando o dado não estava claro.

Solução

Fonte obrigatória + null

Campo fonte ou pagina_pdf obrigatório no schema. Sem origem, vira null com _nota.

Diagnóstico em 60 segundos

  1. 1.Pegue 3 linhas aleatórias da saída da IA.
  2. 2.Abra a página citada do PDF de origem.
  3. 3.O número aparece literalmente ali?
  4. 4.Se não — alucinação. Refaça com prompt mais restritivo.

Prevenção: padrão de prompt blindado

Regras inegociáveis:
  1. Toda linha precisa ter campo "fonte" ou "pagina_pdf"
  2. Se você não encontrar a origem exata: valor_brl = null
     + campo "_nota" explicando por que não foi possível mensurar
  3. NUNCA aproxime. NUNCA infira. NUNCA chute.
  4. "Parece razoável" não é critério — citação é.

Lição prática

A IA inventa com confiança. Toda saída numérica precisa de um endereço auditável de volta para a fonte. Sem isso, é fantasia bem escrita.
