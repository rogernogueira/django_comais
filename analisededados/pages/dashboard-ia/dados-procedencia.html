Dados · 2.4

Procedência: real × inferido

Toda planilha gerada por IA carrega dois tipos de informação. A diferença precisa estar visível no próprio dado.

Real

Extraído do documento

Cada linha tem campo fonte ou pagina_pdf apontando para o local exato.

→ Auditável. Reproduzível.

Inferido

Estimado para completar

Cada linha tem campo _nota ou origem: "inferido" explicando a estimativa.

→ Útil para demonstração. Substituir antes de uso real.

Exemplo concreto (caso CGU)

{
  "codigo": "2.2.1",
  "categoria": "nao_corrigida_valor",
  "descricao": "Ausência de reavaliação de 72,58% dos imóveis do MS",
  "valor_brl": null,                    // ← não mensurável
  "_nota": "Distorção não mensurada — depende de reavaliação que ainda não ocorreu",
  "impacto": "alto",
  "situacao": "pendente",
  "pagina_pdf": 13                       // ← citação real
}

Como mostrar na interface

  • ›Tabela detalhada: mostrar o ícone "✓ fonte verificada" ou "⚠ estimativa".
  • ›KPIs: incluir nota de rodapé "inclui estimativas" quando aplicável.
  • ›Gráficos: hachura/transparência diferente para dado inferido.
  • ›Documento: README que explica a procedência geral.

Lição prática

A diferença entre "demonstração bonita" e "documento confiável" está num único campo: o rótulo de procedência. Sem ele, todo número fica igual — e a confiança vira tudo ou nada.
