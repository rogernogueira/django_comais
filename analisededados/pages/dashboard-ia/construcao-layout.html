Layout responsivo com CSS Grid

Grade de 12 colunas. Cards ocupam frações. Em tela estreita, tudo vira coluna única.

CSS Grid em 10 linhas

.grid {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
  gap: 16px;
}

.col-6  { grid-column: span 6; }   /* meia largura  */
.col-4  { grid-column: span 4; }   /* terço         */
.col-12 { grid-column: span 12; }  /* largura total */

@media (max-width: 980px) {
  .col-6, .col-4 {
    grid-column: span 12;   /* mobile: tudo cheio */
  }
}

Princípios de grade de 12

  • ›12 é divisível por 2, 3, 4, 6: dá flexibilidade para meio, terço, quarto, dois-terços.
  • ›Cards ocupam 6, 4 ou 12 colunas: outras frações funcionam, mas estas três cobrem a maioria.
  • ›Tela estreita = coluna única: em mobile, lutar por layout 2×2 vira ilegível.
  • ›Gap consistente: 16px ou 20px entre cards. Espaço respira.

Cuidado com Chart.js no responsivo

Chart.js precisa de dimensão definida pelo container. Sem isso, ele pode crescer infinitamente:

.chart-wrap {
  position: relative;
  height: 280px;           /* altura explícita */
}

// No options do Chart.js:
options: {
  responsive: true,
  maintainAspectRatio: false,   /* ← chave! */
}

Lição prática

Sempre teste numa tela estreita antes de entregar. Layout que parece bom no desktop pode ficar inutilizável no celular. CSS Grid + um media query resolve 90% dos casos.
