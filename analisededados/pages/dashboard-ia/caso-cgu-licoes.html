Lições aprendidas

O que funcionou e o que precisaria de mais trabalho — reflexão honesta sobre o caso real.

O que funcionou

  • ✓Schema explícito + enums: zero ambiguidade nos filtros do dashboard.
  • ✓Contagem antes do JSON: flagrou itens faltando no primeiro turno — antes de gastar tempo validando.
  • ✓Campo _nota rotulando inferências: separa "real" de "estimado" no próprio dado.
  • ✓Try/catch por gráfico: quando o CDN do treemap deu 404, a tabela ainda apareceu.
  • ✓Stack simples (HTML+Chart.js): qualquer pessoa abre, sem setup.

O que precisaria de mais trabalho

  • ⚠% de reavaliação dos demais órgãos foi inferido: só MS aparece com 72,58% no relatório. Os demais (Fiocruz, GHC etc.) foram estimados para o gráfico funcionar. Precisa de fonte real.
  • ⚠IDs de recomendações: só dois (#1707415, #1707431) são literais do relatório. Os demais foram inferidos para manter o relacionamento 1:N. Antes de uso real, substituir pelos IDs verdadeiros.
  • ⚠Provisões judiciais ficaram como "risco": a CGU não mensurou — não dá para mostrar valor. Solução: campos null + nota explicativa.
  • ⚠Comparação 2023 × 2024 não foi implementada: exigiria buscar o relatório do ano anterior e modelar a série histórica.

Aprendizados-chave

  1. 1.A decomposição em 4 etapas funciona: extração → modelagem → curadoria → entrega. Pular qualquer uma vira improviso.
  2. 2.Outlier real importa: os R$ 21,9 bi de estoques forçaram escala log no gráfico de valor. Sem isso, todo o resto sumia.
  3. 3.null não é exceção: 60% dos achados não tinham valor mensurado. Tratamento de null não é detalhe — é central.
  4. 4.Iteração cirúrgica vale ouro: quando descobrimos o bug do CDN, conserto cirúrgico (URL + try/catch) resolveu sem refazer nada.
  5. 5.Rotular inferência é não-negociável: num dashboard educacional, é didática; num dashboard real, é integridade.

Conclusão geral

A IA não vai pensar por você. Vai pensar com você — se você for específico sobre onde a ajuda começa e onde sua decisão começa. O dashboard funciona. Os números, parcialmente verificados. As lições, totalmente aplicáveis.
