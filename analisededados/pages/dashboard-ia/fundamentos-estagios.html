Fundamentos · 1.2

Os 4 estágios da construção

Todo dashboard nasce numa sequência. Pular etapas significa improvisar — e improvisar custa caro.

A cadeia completa

ESTÁGIO 1

Extração

Tirar dados de onde estão: PDF, planilhas, APIs, banco. Resultado: arquivo estruturado.

ESTÁGIO 2

Modelagem

Organizar em tabelas relacionadas. Definir chaves, tipos e regras.

ESTÁGIO 3

Visualização

Decidir quais gráficos respondem quais perguntas. Não é decisão estética.

ESTÁGIO 4

Entrega

Montar a interface: filtros, layout, responsividade, acessibilidade.

Por que essa ordem (e não outra)

Cada estágio depende do artefato do anterior. Se você inverte, vai pedir à IA que invente — e ela inventa.

  • ›Não dá para modelar tabelas sem saber quais campos os achados têm.
  • ›Não dá para escolher gráfico sem saber quantos valores existem em cada categoria.
  • ›Não dá para montar o dashboard sem ter os dados prontos.

Checkpoints entre etapas

Entre cada estágio, pare e olhe a saída antes de avançar:

[ ] A saída faz sentido para o domínio?

[ ] Os números batem com o documento de origem?

[ ] Sobrou algo importante de fora?

[ ] Os enums (categorias fechadas) estão consistentes?

[ ] Há rastreabilidade da origem de cada dado?

Lição prática

Se você só pergunta "está bom?" depois de receber o dashboard final, fica caro voltar. Checkpoint de 2 minutos entre cada etapa economiza 2 horas de retrabalho no fim.
