Validação humana — checklist obrigatório

A validação não é opcional. É o que separa "demonstração bonita" de "documento confiável".

Checklist antes de seguir para a próxima etapa

[ ] A soma dos valores bate com o total declarado na fonte?

[ ] Toda página citada existe e fala daquele assunto?

[ ] Os enums têm exatamente os valores combinados?

[ ] Todo valor null tem campo _nota explicando?

[ ] As descrições respeitam o limite de palavras?

[ ] Não há duplicatas no campo de código?

[ ] As chaves estrangeiras entre tabelas casam?

Sinais de alerta durante a validação

  • ⚠Números muito redondos onde a fonte tem precisão decimal.
  • ⚠Descrições genéricas ("conforme normas vigentes") onde a fonte é específica.
  • ⚠Páginas citadas que não falam do tema.
  • ⚠Categorias que "parecem" certas mas não estão no enum fornecido.
  • ⚠Total não bate com a soma das partes.

Lição prática

A validação humana não é opcional — é o passo que torna o dashboard auditável. Sem ela, você tem um produto com cara de profissional e fundamento de palpite.
