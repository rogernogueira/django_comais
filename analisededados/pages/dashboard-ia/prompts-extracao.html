Prompt 1 — Extração

Primeiro prompt da cadeia: texto → JSON estruturado.

O prompt completo

Extraia do PDF anexo todos os itens do capítulo X. Devolva em
JSON com a chave "itens", lista de objetos contendo:

  codigo:     string "x.y.z"
  categoria:  enum ["corrigida", "nao_corrigida_valor",
                    "classificacao", "inconformidade"]
  tema:       enum [...8 valores...]
  unidade:    string
  descricao:  string (≤ 25 palavras)
  valor:      número | null
  impacto:    "alto" | "medio" | "baixo"
  pagina_pdf: número

Regras:
  - Não invente valores. Use null e crie campo "_nota" explicando.
  - Cite a página de origem de cada item.
  - Devolva apenas o JSON, sem texto antes ou depois.

Antes do JSON, liste quantos itens você identificou em cada
categoria. Eu confirmo. Só depois você gera o conteúdo completo.

Anatomia das partes do prompt

  • 1.Tarefa concreta: "Extraia do PDF anexo" — não "leia o documento e me diga".
  • 2.Formato de saída: JSON com chave nomeada — facilita parsing.
  • 3.Schema explícito: cada campo tipado e com restrições.
  • 4.Regras anti-alucinação: "não invente", "use null", "cite página".
  • 5.Checkpoint final: contagem antes do conteúdo.

O que sai (exemplo)

{
  "itens": [
    {
      "codigo":     "2.1.1",
      "categoria":  "corrigida",
      "tema":       "estoques",
      "unidade":    "MS/DLOG",
      "descricao":  "Correção em Importações em Andamento — Estoques",
      "valor":      21900000000,
      "impacto":    "alto",
      "pagina_pdf": 11
    },
    /* ... mais 19 itens ... */
  ]
}

Lição prática

Este é o prompt mais importante da cadeia. Se a extração sai ruim, tudo a seguir herda o problema. Vale a pena gastar tempo polindo este.
