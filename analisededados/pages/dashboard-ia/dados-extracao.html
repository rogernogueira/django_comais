Extração: de texto bruto a dado estruturado

A primeira etapa: a IA lê o documento longo e devolve dado máquina-legível.

O fluxo

Entrada

Texto, PDF, planilha — linguagem natural, formato variado, dados misturados a narrativa.

Operação

A IA lê e devolve em formato máquina-legível (JSON, CSV), respeitando um schema definido por você.

Saída

Cada campo nomeado, tipado, com restrições e origem rastreável.

Exemplo: trecho de relatório → JSON

Texto original

"Foi identificada distorção na conta
de Importações em Andamento de Bens
Móveis, no valor de R$ 235 milhões,
corrigida ao longo da auditoria.
(página 12)"

JSON estruturado

{
  "codigo": "2.1.2",
  "categoria": "corrigida",
  "tema": "patrimonio_moveis",
  "descricao": "Bens Móveis em Importação",
  "valor_brl": 235114529.82,
  "pagina_pdf": 12
}

Cuidados antes de pedir extração

  • ›Documento confidencial? Antes de colar em chat público, confirme a política de dados.
  • ›PDF é texto ou imagem? PDFs digitalizados (imagem) precisam de OCR antes.
  • ›Sei o escopo? "Extraia tudo" produz lixo; "extraia o capítulo X com schema Y" produz dado.

Lição prática

Extração sem schema é achar dados aleatórios. Extração com schema é preencher uma planilha. A diferença é qualidade: a primeira você joga fora; a segunda você usa.
