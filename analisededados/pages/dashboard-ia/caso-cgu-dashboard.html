Stack técnica

  • ›HTML5 + Vanilla JS (sem framework)
  • ›Chart.js 4.4.1 via CDN
  • ›Plugins: chartjs-chart-treemap, chartjs-chart-matrix
  • ›CSS embutido com CSS Grid responsivo
  • ›Dados embutidos no script (20 achados, 15 recomendações)
  • ›Try/catch em cada render — gráficos isolados

Resultado

Um arquivo dashboard.html de ~600 linhas. Abre direto no navegador. Sem instalação. Sem servidor. Tudo o que o gestor precisa numa tela.
