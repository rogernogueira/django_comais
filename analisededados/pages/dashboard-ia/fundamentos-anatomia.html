Fundamentos · 1.3

Anatomia de um dashboard bem feito

Cinco regiões com funções distintas. Quando uma falta, o usuário sente.

As cinco regiões

1. Cabeçalho

Título descritivo do conteúdo + data de atualização + botão "limpar filtros". Opcional: exportar para PDF/CSV.

2. Filtros

Entre 3 e 6 dimensões. Multi-select por padrão. Sempre visíveis (não escondidos atrás de cliques).

3. Linha de KPIs

Três a cinco cards com os números mais importantes. Respondem "em uma piscada, qual o tamanho do problema?".

4. Grade de gráficos

Cada gráfico responde uma pergunta. Ordem do mais agregado para o mais granular. Layout em grid de 2 ou 3 colunas.

5. Tabela detalhada

Drill-down completo. Cada linha é um item; cada coluna é um atributo. Permite auditar as afirmações dos gráficos.

Lição prática

A tabela detalhada é a região mais subestimada do dashboard. Ela é o que prova os números dos gráficos. Dashboard sem tabela vira "confie em mim". Com tabela, vira "veja você mesmo".
