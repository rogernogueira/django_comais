Armadilhas · 8.5

CSV mal formado

Vírgulas nas descrições viram colunas extras. Acentos viram lixo. Excel BR vê tudo errado.

Sintoma

Colunas embaralhadas

Abrir no Excel BR mostra colunas extras, acentos quebrados, números como texto.

Causa

Falta escaping

Campos com vírgula não estão entre aspas. Arquivo não está em UTF-8 com BOM.

Solução

RFC 4180 + BOM

Aspas duplas envolvendo campos especiais. Aspas internas duplicadas. UTF-8 com BOM para Excel BR.

Os 4 erros mais comuns

  • 1. Vírgula no campo sem aspas

    codigo,descricao
2.1.1,Achado, com vírgula  ← vira "Achado" e " com vírgula"

  • 2. Separador de milhar nos números

    valor
1.000.000,50  ← Excel BR pode interpretar como string

  • 3. Sem UTF-8 + BOM

    descricao
Reavaliaç„o de imÛveis  ← acentos quebrados no Excel

  • 4. "null" como texto

    valor
null  ← deveria ser célula vazia para filtros funcionarem

CSV bem formado (RFC 4180)

codigo,categoria,descricao,valor
2.1.1,corrigida,"Achado importante, com vírgula",21900000000
2.2.1,pendente,"Outro ""com aspas"" dentro",
2.4.6,inconformidade,Sem caracter especial,13000000

# Regras:
#   - Aspas envolvem campos com vírgula ou aspas
#   - Aspas internas duplicadas: " vira ""
#   - Número: ponto decimal, sem separador de milhar
#   - Null = célula vazia (não "null")

Lição prática

CSV mal formado é o tipo de bug que aparece tarde: tudo funciona até alguém abrir no Excel BR e ver as colunas embaralhadas. Convenções aqui custam segundos; debugar custa horas.
