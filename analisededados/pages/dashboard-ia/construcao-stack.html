Construção · 6.1

Stack mínima: HTML + Vanilla JS + Chart.js

Um arquivo. Um navegador. Zero dependência local. Suficiente para 95% dos dashboards didáticos.

Os três componentes

HTML

Estrutura

Marcação semântica: <header>, <section>, <table>. Filtros como <select>.

CSS

Layout

CSS Grid responsivo, variáveis CSS para paleta. Tailwind via CDN é opcional.

JS

Comportamento

Vanilla JS para filtros e estado. Chart.js (com plugins) para gráficos. Sem framework.

Por que evitar React, Vue, Streamlit (para casos simples)

  • ×Complexidade de build: webpack, vite, package.json, node_modules. Para 1 arquivo?
  • ×Dependências: 200 pacotes para mostrar 10 gráficos é desproporcional.
  • ×Ciclo de deploy: compilar, hospedar, configurar. Em vanilla, você duplo-clica e abre.
  • ×Streamlit/Dash: precisa de Python rodando — não funciona em qualquer máquina sem setup.

CDNs comuns

<!-- Chart.js (núcleo) -->
<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js"></script>

<!-- Plugin para treemap -->
<script src="https://cdn.jsdelivr.net/npm/chartjs-chart-treemap@2.3.1/dist/chartjs-chart-treemap.min.js"></script>

<!-- Plugin para matrix/heatmap -->
<script src="https://cdn.jsdelivr.net/npm/chartjs-chart-matrix@2.0.1/dist/chartjs-chart-matrix.min.js"></script>

<!-- Tailwind (opcional) -->
<script src="https://cdn.tailwindcss.com"></script>

Lição prática

"Stack pequena" é decisão estratégica. Reduz fricção para o usuário rodar, para você manter e para a IA gerar. Comece simples; complica só se a complexidade pagar.
