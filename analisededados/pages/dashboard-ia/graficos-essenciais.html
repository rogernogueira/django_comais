Quando NÃO usar KPI

Quando o gestor precisa comparar valores entre categorias — aí use barras.

Barras — o cavalo de batalha

Verticais

Até 6–8 categorias e rótulos curtos. Eixo Y é a métrica.

Horizontais

Muitas categorias ou rótulos longos. Eixo X é a métrica.

Empilhadas

Composição por categoria. 100% empilhadas = proporção.

Regra de ordenação

Decrescente por valor — exceto se a categoria tem ordem natural (meses, estágios). Ordenação alfabética é quase sempre errada.

Lição prática

Se você só pudesse usar dois tipos de gráfico, seriam KPIs e barras. Tudo o mais é especialização. Domine os dois antes de partir para variações.
