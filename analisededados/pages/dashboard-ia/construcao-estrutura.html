Estrutura de um dashboard standalone

Um arquivo HTML, tudo embutido, abre direto. Aqui está o esqueleto.

Esqueleto completo

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Dashboard X</title>
  <script src="https://cdn.jsdelivr.net/.../chart.js"></script>
  <style>
    /* paleta + grid + cards */
  </style>
</head>
<body>
  <header>
    <h1>Título</h1>
    <button id="reset">Limpar filtros</button>
  </header>

  <section class="filters">
    <select id="f-unidade" multiple>...</select>
    <select id="f-tema" multiple>...</select>
  </section>

  <main>
    <div class="kpi-row" id="kpis"></div>
    <div class="grid">
      <canvas id="grafico-1"></canvas>
      <canvas id="grafico-2"></canvas>
    </div>
    <table id="detail">...</table>
  </main>

  <script>
    const DATA = [/* dados embutidos */];
    const FILTERS = {/* estado */};
    function filtered() {...}
    function refreshAll() {...}
    refreshAll();
  </script>
</body>
</html>

As cinco regiões funcionais

  1. 1.<head> — CDNs + CSS embutido. Tudo o que carrega antes do conteúdo.
  2. 2.<header> — Título + ações globais (reset, exportar).
  3. 3.<section.filters> — Selects multi-select, sempre visíveis.
  4. 4.<main> — KPIs, grade de gráficos, tabela detalhada.
  5. 5.<script> no final do body — dados embutidos + funções de render.

Por que o script no final

Coloque o <script> antes de </body>:

  • ›O DOM já está renderizado quando o JS roda
  • ›document.getElementById('...') funciona direto
  • ›Não precisa de DOMContentLoaded

Lição prática

Mantenha o arquivo autocontido. Quanto menos pedaços externos, menos coisa para quebrar quando alguém compartilhar o HTML por email.
