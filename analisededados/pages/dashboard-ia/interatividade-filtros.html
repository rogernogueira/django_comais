Interatividade · 5.1

Filtros como linguagem de exploração

Filtros não são adornos. Eles são a forma como o usuário fala com o dashboard.

Princípio

Cada filtro é uma pergunta latente:

  • ›"E se eu olhar só a unidade X?" → filtro de unidade
  • ›"E se eu olhar só achados pendentes?" → filtro de situação
  • ›"E se eu olhar só o período da gestão anterior?" → filtro temporal

Quantidade ideal: 3 a 6

< 3

Pouca exploração possível. Dashboard fica "estático".

3 a 6

Faixa ideal. Cobre as dimensões importantes sem sobrecarregar.

> 6

Paralisia de escolha. Usuário não sabe o que combinar.

Multi-select × single-select

Multi-select (padrão)

"Quero unidades A, B e C". Permite combinações ricas. Use para a maioria dos filtros.

Single-select

Para dimensões mutuamente exclusivas — ex.: "comparar com" = ano anterior ou média histórica.

Como apresentar visualmente

  • ›Sempre visíveis — não escondidos atrás de cliques.
  • ›Barra superior ou lateral fixa — em ambos os casos, fácil de encontrar.
  • ›Botão "limpar filtros" sempre presente.
  • ›Indicador de filtro ativo — "Mostrando 12 de 20 achados".

Lição prática

Filtros são verbos; gráficos são substantivos. Dashboard sem filtro é só substantivo — narração passiva do que aconteceu. Com filtro, vira diálogo.
