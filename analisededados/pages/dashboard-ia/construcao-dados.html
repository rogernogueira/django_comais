Construção · 6.3

Dados embutidos × dados externos

Onde os dados moram? A escolha muda completamente o ciclo de uso do dashboard.

Comparativo

Aspecto Embutidos no HTML Arquivo externo
SetupZero — abre diretoPrecisa de servidor local ou CORS
Tamanho aceitávelAté ~10 mil linhasQualquer tamanho
AtualizaçãoReeditar o HTMLTrocar só o arquivo de dado
CompartilhamentoUm único arquivoMúltiplos arquivos
Versão dos dadosAtrelada ao HTMLIndependente

Embutidos — exemplo

// dentro do <script> do HTML
const DATA = [
  { codigo: "2.1.1", categoria: "corrigida", valor: 21900000000 },
  { codigo: "2.1.2", categoria: "corrigida", valor: 235114529.82 },
  /* ...mais 18 linhas... */
];

// renderização usa DATA direto, sem fetch

Externos — exemplo

// carrega o CSV externo
async function loadData() {
  const res = await fetch('./achados.csv');
  const text = await res.text();
  return parseCSV(text);  // sua função de parsing
}

loadData().then(data => {
  DATA = data;
  refreshAll();
});

⚠ Atenção: navegadores bloqueiam fetch('./arquivo.csv') ao abrir HTML direto (file://). Precisa servir via HTTP local.

Lição prática

Dashboard didático ou one-off? Embutido. Dashboard que atualiza periodicamente? Externo, com cache. A regra é o ciclo de uso — não a sofisticação técnica.
