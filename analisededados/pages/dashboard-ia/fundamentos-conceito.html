Fundamentos · 1.1

O que é um dashboard analítico

Interface visual que condensa estado e tendência de um domínio em uma única tela — para monitorar, comparar e investigar.

Definição operacional

Um dashboard analítico é uma interface visual que reúne em uma só tela métricas, gráficos e filtros que respondem perguntas recorrentes sobre um domínio. Diferente de um relatório, ele é interativo e atualizável; diferente de uma planilha, ele é prescritivo sobre o que importa olhar.

As três funções essenciais

1. Monitorar

Mostrar o estado atual dos indicadores-chave. KPIs no topo da tela respondem "como estamos agora?".

2. Comparar

Permitir cortes por dimensão (unidade, tema, tempo) para responder "onde está concentrado?" e "como mudou?".

3. Investigar

Drill-down do agregado ao detalhe individual — para responder "quais exatamente?" sem trocar de ferramenta.

O que NÃO é um dashboard

  • ×Um relatório longo em PDF: não tem interatividade, e o leitor precisa rolar para encontrar o que importa.
  • ×Uma coleção aleatória de gráficos bonitos: bonito sem pergunta de negócio vira ruído.
  • ×Uma planilha colorida: cor decorativa não é a mesma coisa que cor com semântica.
  • ×Um substituto para análise profunda: o dashboard mostra o "o quê"; o "por quê" continua sendo trabalho humano.

Lição prática

Se você não consegue listar três perguntas concretas que o gestor vai fazer ao olhar a tela, ainda não está pronto para projetar o dashboard. Volte e converse com quem vai usar.
