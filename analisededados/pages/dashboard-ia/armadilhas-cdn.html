Armadilhas · 8.4

Dependência quebrada (CDN errado)

URL errada de plugin → erro em cascata → metade do dashboard some sem aviso.

Sintoma

Gráficos faltando

Parte dos gráficos não renderiza. A tabela detalhada também não aparece. Console com erros vermelhos.

Causa

URL retorna 404

Plugin foi carregado com nome de arquivo errado. Quando o código tenta usar o tipo de gráfico, dá erro — e derruba a cadeia.

Solução

URL correta + try/catch

Verificar URL do CDN no console + envolver cada render em try/catch.

Caso real: chartjs-chart-treemap

Errado (404)

.../chartjs-chart-treemap.umd.min.js

Certo (200)

.../chartjs-chart-treemap.min.js

Confira sempre no navegador a URL exata clicando no link do CDN. Não confie em "parece certo".

Blindagem com try/catch

function safe(label, fn) {
  try { fn(); }
  catch (e) { console.error("[" + label + "]", e); }
}

function refreshAll() {
  const data = filtered();

  // Tabela e KPIs primeiro — nunca podem ficar vazios
  safe("table", () => renderTable(data));
  safe("kpis",  () => renderKPIs(data));

  // Cada gráfico isolado
  safe("treemap",  () => renderTreemap(data));
  safe("heatmap",  () => renderHeatmap(data));
  safe("bubble",   () => renderBubble(data));
  /* ... etc ... */
}

Lição prática

Ordem importa. Renderize a tabela primeiro — ela é a "âncora de verdade". Se algum gráfico falhar, pelo menos os dados continuam visíveis. try/catch por gráfico é defesa contra futuras alterações também.
