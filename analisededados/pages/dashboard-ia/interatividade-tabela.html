Interatividade · 5.4

Tabela detalhada — a âncora de confiança

Os gráficos resumem. A tabela prova. Sem ela, o dashboard vira "confie em mim".

O que colocar

  • ›Toda coluna da tabela principal: o usuário precisa ver o dado bruto, não uma versão "filtrada para o gráfico".
  • ›Colunas derivadas com tags: impacto, situação, categoria viram tags coloridas — mais legível que texto puro.
  • ›Fonte sempre que possível: link, página, ou identificador externo. Sem isso, o número fica órfão.
  • ›Indicador de procedência: ✓ verificado vs ⚠ inferido.

Recursos importantes

Scroll vertical com cabeçalho fixo

position: sticky; top: 0 no <thead>. Usuário sempre vê os nomes das colunas.

Ordenação por coluna

Clique no cabeçalho ordena por aquela coluna. Indicador visual (↑↓).

Linhas com hover

Realce sutil ao passar o mouse — facilita acompanhar a linha de olho.

Exportar CSV

Botão "exportar visível" gera CSV do que está filtrado. Auditoria fica fácil.

Erros comuns

  • ⚠Esconder a tabela em outra aba — perde a função de âncora.
  • ⚠Mostrar só as colunas "bonitas" — esconder a fonte é esconder a verdade.
  • ⚠Não responder a filtros — tabela "estática" desconecta do resto.
  • ⚠Truncar texto sem opção de expandir — perda de informação.

Lição prática

A tabela detalhada é a região mais subestimada do dashboard. Ela é o que torna os gráficos auditáveis. Sem ela, qualquer afirmação fica indefensável.
